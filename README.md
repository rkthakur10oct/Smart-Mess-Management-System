Smart Mess Management System is a C++ console-based application designed to manage hostel mess operations efficiently. The system uses file handling and OOP concepts to digitize and simplify mess management.
🍽️ Smart Mess Management System

A C++ console-based application designed to manage hostel mess operations efficiently. The system includes Admin, Student, and Staff modules to handle user management, menu viewing, attendance tracking, salary status, and feedback. It uses Object-Oriented Programming and file handling to digitize traditional mess management.

🚀 Features

Admin dashboard for managing students and staff

Student login to view profile, menu, attendance, and dues

Staff login to check profile, attendance, and salary status

Weekly mess menu management

Feedback system

File-based data storage

🛠️ Technologies Used

C++

OOP Concepts

File Handling
